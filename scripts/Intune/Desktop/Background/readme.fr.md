# Background

Déploiement du fond d'écran et de l'écran de verrouillage de l'entreprise via Intune. Les deux utilisent le même modèle de configuration `$ImageUrl` / `$ClientName` et PersonalizationCSP pour l'application via MDM.

---

## Dossiers

| Dossier | Description |
|--------|-------------|
| [`Desktop/`](Desktop/readme.fr.md) | `Set-CorporateWallpaper.ps1` — définit le fond d'écran du bureau |
| [`Lockscreen/`](Lockscreen/readme.fr.md) | `Make-lockscreen.ps1` — définit l'image de l'écran de verrouillage |

Consultez le readme de chaque sous-dossier pour la configuration, le déploiement et la journalisation.
