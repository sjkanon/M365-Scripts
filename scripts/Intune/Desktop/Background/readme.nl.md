# Background

Uitrol van de bedrijfsachtergrond en het vergrendelscherm via Intune. Beide gebruiken hetzelfde configuratiepatroon met `$ImageUrl` / `$ClientName` en PersonalizationCSP voor afdwinging via MDM.

Zie de readme van elke submap voor configuratie, uitrol en logging.
