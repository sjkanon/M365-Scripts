# Custom Scripts

Scripts figés à leur emplacement actuel parce qu'autre chose dépend de ce chemin exact — actuellement : le déploiement des thèmes Office, dont les scripts ont une URL de téléchargement codée en dur pointant vers ce dépôt. Tout le reste, générique et réutilisable, se trouve dans les dossiers de catégorie de premier niveau de [`scripts/`](../readme.fr.md).

---

## Dossiers

| Dossier | Description |
|--------|-------------|
| [`Intune/`](Intune/readme.fr.md) | Déploiement des thèmes/couleurs Office (`Deploy-OfficeTheme.ps1`, `Deploy-Officecolors.ps1`) — lié à son chemin ; voir [`scripts/Intune/`](../Intune/readme.fr.md) pour le reste des outils Intune |
