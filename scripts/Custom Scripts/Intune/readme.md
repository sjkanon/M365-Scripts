# Intune (Custom Scripts)

Office theme/color deployment — kept separate from [`scripts/Intune/`](../../Intune/readme.md) for historical reasons: `Deploy-OfficeTheme.ps1` and `Deploy-Officecolors.ps1` used to hardcode their download URL to this repo path.
