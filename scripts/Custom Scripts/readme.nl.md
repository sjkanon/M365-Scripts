# Custom Scripts

Scripts die vastzitten aan hun huidige pad omdat iets anders van precies die locatie afhangt — op dit moment: de uitrol van Office-thema's, waarvan de scripts een download-URL naar deze repo hard gecodeerd hebben. Al het andere dat generiek/herbruikbaar is, staat onder de categoriemappen op het hoogste niveau in [`scripts/`](../readme.nl.md).
