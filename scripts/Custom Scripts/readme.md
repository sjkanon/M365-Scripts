# Custom Scripts

Customer- and use-case-specific scripts that don't fit cleanly into a generic workload category. For the generic/reusable M365 tooling, see [`Entra/`](../Entra/readme.md), [`Exchange/`](../Exchange/readme.md), [`Graph/`](../Graph/readme.md), [`Intune/`](../Intune/readme.md), [`Reporting/`](../Reporting/readme.md) and [`Testing Scripts/`](../Testing%20Scripts/readme.md) in the parent `scripts/` folder.

---

## Categories

| Folder | Description |
|--------|-------------|
| [`device/`](device/readme.md) | Windows endpoint maintenance — activation, cleanup, temp files, time sync, audio |
| [`Intune/`](Intune/readme.md) | Customer-specific Intune desktop deployment (Office theme, wallpaper, lockscreen) |
| [`DNS/`](DNS/readme.md) | Resolve and import DNS records into AD-integrated DNS zones |
| [`SAS/`](SAS/readme.md) | SAS batch job error monitoring with Zabbix integration |
| [`Save install time/`](Save%20install%20time/readme.md) | USB toolkit for Windows setup and Autopilot enrollment during OOBE |
